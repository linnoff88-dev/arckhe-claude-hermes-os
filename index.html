O que é

Um painel que mostra — e melhora — toda a sua operação com IA

Não é mais um app pra você configurar do zero. É um scaffold pronto, lindo, que o próprio Claude instala e preenche com os dados reais da sua máquina. A regra de ouro: o front nunca toca seus arquivos direto — um único agregador lê o disco (somente leitura) e gera um live-data.json.

📊 Vê tudo num lugar

Gasto por modelo, sessões por dia, grafo de memória 3D, skills ativas, conexões (Obsidian, Pinecone, MCP) e atividade por projeto — agregado do seu Claude Code, Codex e mais.

🌙 Melhora sozinho (Dream)

Todo dia ele audita suas últimas 24h em 8 frentes (custo, skills, automação, ROI…) e entrega as 4 melhores recomendações, cada uma com um botão "rodar a correção".

🪽 Tem o Hermes embutido

Um assistente pessoal com panteão de personas, chat dentro do painel, backup diário no GitHub e ponte com o Obsidian. Metas e insights espelhados entre Claude e Hermes.

Privacidade primeiro. Os dados de origem (~/.claude/, Obsidian, etc.) são lidos só pra leitura — nunca escritos. A anonimização vem ligada por padrão (reescreve seu usuário/e-mail) e o live-data.json com seus dados reais fica fora do versionamento.
Como funciona

Do download ao painel vivo

O agregador é o único ponto que toca o disco. Ele varre suas ferramentas, escreve um JSON, e o app (TanStack Start + Vite, rodando em Bun) renderiza tudo. Um pequeno sidecar local (porta 17873, só loopback) liga os botões "ativar" e "rodar correção".

Baixar o arquivo→ Claude abre e segue o CLAUDE.md→ bun install · setup · dev→ Agregador varre a máquina→ live-data.json→ Painel no navegador

O que ele lê

~/.claude/, ~/.codex/, ~/.openclaw/, vaults do Obsidian, Pinecone (via API key) e OpenRouter — além de servidores MCP e tarefas agendadas.

O que ele gera

live-data.json (seus dados, fora do git) e o dream-{data}.json do dia. O front só lê esses dois — todo o resto é derivado.

Onde roda

App em Bun + Vite no navegador local. Otimizado pra macOS (agregador, detecção de plano, cron diário). Em Linux/Windows roda principalmente em modo demo.

Pré-requisitos

O que você precisa antes de começar

É um arquivo exclusivo da comunidade (não um repositório público) — você baixa o .zip e o próprio Claude faz o resto. O essencial: Bun, o Claude Code, e o arquivo.

📦 O arquivo (.zip)

Baixe na comunidade, descompacte e tenha a pasta à mão (ex.: ~/code/claude-os).

# descompacte onde preferir
unzip claude-os.zip -d ~/code/

⚡ Bun

O runtime que roda o setup e o servidor.

# instala o Bun (macOS/Linux)
curl -fsSL https://bun.sh/install | bash

🤖 Claude Code

É quem abre a pasta e segue as instruções pra você. Chaves de API (OpenRouter, OpenAI, Pinecone) são opcionais e destravam mais painéis.

# confira que está instalado
claude --version
Guia de uso · passo a passo

Instale, configure e domine em 8 passos

Do download ao Hermes rodando. Os comandos são reais — o pulo do gato é deixar o Claude Code conduzir a instalação enquanto você responde o onboarding no navegador.

1

Baixe e descompacte o arquivo

Pegue o .zip na comunidade, descompacte e guarde o caminho. Como é exclusivo do grupo, ele vem como arquivo (não como repo público).

unzip claude-os.zip -d ~/code/   # vira ~/code/claude-os
2

Mande o Claude Code abrir e seguir as instruções

Abra o Claude Code na pasta e cole o pedido abaixo. O CLAUDE.md de dentro do arquivo já traz tudo que ele precisa saber pra configurar na sua máquina. Ele pede permissão uma vez — você diz sim.

Instale o Claude OS pra mim. Os arquivos já estão em ~/code/claude-os.
Peça permissão uma vez e rode, em ordem, sem mais perguntas:
  1. cd ~/code/claude-os && bun install
  2. cd ~/code/claude-os && bun run setup
  3. cd ~/code/claude-os && bun run dev
Depois seja meu guia de onboarding e me pergunte o que tenho no stack.
3

Os três comandos (o que cada um faz)

setup faz o trabalho pesado: varre a máquina, copia a skill /dream, instala o cron diário e marca pro wizard abrir. dev sobe o app + o sidecar e abre o navegador.

bun install                # dependências
bun run setup              # varre a máquina + prepara o ambiente
bun run dev                # sobe o painel e abre o wizard no navegador
4

Faça o onboarding (7 passos no navegador)

O wizard abre sozinho. Em ordem: (1) seu nome + foto (personaliza tudo, ótimo pra mostrar a clientes); (2) ele auto-detecta suas ferramentas (Codex, Claude, Terminal, Hermes…); (3-4) conecta Obsidian e Pinecone; (5) chaves de API (OpenRouter/OpenAI) pra rastrear gasto; (6) "quanto vale sua hora" pra calcular tempo economizado; (7) configura o Dream e ativa. Confete. 🎉

Não achou alguma ferramenta sua? É normal — são milhões de combinações. Peça ao Claude: "uso a ferramenta X e não vi no Claude OS, adiciona pra mim aqui?" É assim que ele vira seu.
5

Passeie pelo painel

Home com seu gasto de IA (auto-detectado), grafo de memória 3D (wiki, pessoas, núcleo de memória), skills (dezenas de capacidades), conexões (Obsidian, Pinecone, MCP — dá pra ligar/desligar), tarefas agendadas, sessões por dia e atividade. Algo errado? É só dizer ao Claude pra ajustar.

# re-rode o agregador quando quiser atualizar os dados
bun run aggregate
6

Ative o Dream (melhoria diária automática)

Um cron às 7h audita suas últimas 24h em 8 frentes, rankeia por severidade × impacto em R$ e escreve as Top 4 recomendações. Cada card tem um botão "rodar a correção". Custa ~US$1,50–3 por execução, amortizado na sua assinatura (sem chaves novas).

# 1. instala a skill /dream no Claude Code
mkdir -p ~/.claude/skills && cp -r skills/dream ~/.claude/skills/dream
# 2. instala o cron diário (macOS)
bun run install-dream      # --time HH:MM pra mudar a hora
7

Planeje metas com o Mission Control

O planejamento de longo prazo. Você copia o prompt do painel, dá ao Claude (ou ao Hermes) uma meta de médio prazo — tipo "chegar a 500 inscritos no YouTube" — e ele quebra em 4 a 10 prompts encadeados (uns do Claude, uns seus) e monta o roadmap pra você ir completando.

8

Configure o Hermes Agent

O assistente pessoal. No painel você abre o panteão de personas (Mercury, Alquimista…), dá nome/descrição/modelos a cada uma (modelo forte pra raciocínio, modelo barato pra raspar dados) e conversa com o Hermes ali mesmo. Dois prompts importantes: o de backup diário no GitHub (cola no Hermes → ele faz backup todo dia, dá pra "voltar no tempo" se algo quebrar) e o de ponte com o Obsidian.

# no painel do Hermes: copie o prompt de backup e cole no Hermes Agent
Conecte meu Hermes ao GitHub e faça um backup diário automático.
Na prática

O que ele encontra por você

Exemplos reais do tipo de insight que o sistema gera sozinho enquanto você dorme ou trabalha.

💸 "Economizei US$100/mês"

Numa madrugada o Dream notou: o plano Claude Max 20 estava em 10% de uso semanal. Recomendou trocar pro plano 5x — mesma cobertura por metade do preço. Insight com fonte, pronto pra agir.

🧭 Roadmap de uma meta

"Lançar uma lista de e-mail com 1.000 pessoas" vira, no Mission Control, 4–10 prompts encadeados + um roadmap visual pra completar passo a passo — alguns executados pelo Claude, outros por você.

🧠 Memória conectada

O grafo importa seu núcleo de memória, wiki e pessoas, e mostra Obsidian e Pinecone ligados — com chave pra ligar/desligar cada fonte. Tudo navegável em 3D.

🪽 Personas sob medida

No panteão do Hermes, cada persona tem nome, função e o modelo certo pra ela. Metas espelhadas entre Claude e Hermes deixam você planejar no computador ou no celular.
